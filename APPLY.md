# Apply and run

This archive is laid out relative to the repository root.

## 1. Copy into the repository

Extract/copy the bundle over a clone of `Harschul/IBM-AI-August-Challenge`, preserving paths. The only existing file intentionally replaced is:

- `config/prototype.yaml` (currently empty in `main`)

Everything else in the bundle is additive.

## 2. Baseline-only integrated smoke test

Uses the existing root environment (Python 3.11+):

```bash
python -m pytest tests/test_temporal_router.py tests/test_integration.py -q
python run_integrated_demo.py --no-rl --bundles 100
```

Expected outputs:

```text
integrated_results/integrated_bundle_results.csv
integrated_results/integrated_summary.json
```

The runner also prints how many physical contacts were generated, including the number of direct science-to-ground windows.

## 3. Evaluate the existing RL checkpoint on the same physical scenario

Install the combined dependencies:

```bash
pip install -r requirements-integration.txt
```

Then run:

```bash
python run_integrated_demo.py \
  --model RL/rl_env_v0/models/rl_agent_seed_42.zip \
  --bundles 100
```

The baseline and RL+fallback runs receive the same physical contact plan and the same generated bundle set, but each policy gets its own capacity ledger so one policy cannot consume capacity from the other.

## 4. Files to review first

- `config/prototype.yaml` — all explicit simulation assumptions.
- `src/integration/contact_plan.py` — geometry-to-contact conversion and direct-to-ground integration.
- `src/integration/rl_bridge.py` — exact 158-feature/14-action checkpoint interface.
- `src/integration/simulation.py` — capacity commit and deterministic safety fallback.

## 5. Recommended next experiment

Run the current checkpoint first and record the physical-plan score. Then retrain the same MaskablePPO architecture using contact plans generated by `src/integration/contact_plan.py`; do not change the observation/action shape. That gives an apples-to-apples "mock-trained vs physics-trained" result without invalidating the existing model interface.
